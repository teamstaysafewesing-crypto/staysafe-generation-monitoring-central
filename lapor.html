2. Spesifikasi Alur Kerja Laporan (Workflow)

Sistem ini dirancang dengan arsitektur otomatisasi instan untuk memastikan setiap kendala atau laporan pelanggaran dapat ditangani dengan cepat oleh tim inti:

  • Pengisian Data: Pelapor mengisi kategori masalah dan rincian kronologi melalui link formulir di atas.
  • Penyimpanan Basis Data: Data respons masuk secara otomatis ke dalam Google Spreadsheet terkait.
  • Eksekusi Skrip: Google Apps Script membaca baris data baru menggunakan pemicu kejadian OnFormSubmit.
  • Notifikasi Telegram: Pesan format rapi dikirimkan secara instan ke grup chat [ADMIN] Tim Inti Staysafe GMC.

4. Panduan Pemeliharaan & Troubleshooting

Jika notifikasi laporan gagal terkirim ke Telegram, lakukan pengecekan berikut:

  • Periksa kembali menu Ekstensi > Apps Script pada Spreadsheet untuk memastikan fungsi skrip `sendToTelegram(e)` tidak mengalami error sintaksis.
  • Pastikan pemicu waktu/kejadian (Triggers) dengan fungsi `sendToTelegram` masih aktif dan berstatus benar.
  • Jangan mengubah urutan kolom pada Spreadsheet penampung agar pembacaan array data oleh Apps Script tetap konsisten.
